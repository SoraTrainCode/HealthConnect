# Mã nguồn bên thứ ba

- Bootstrap 5.3.3: CSS và JS bundle từ bản phân phối chính thức, giấy phép MIT trong `assets/vendor/BOOTSTRAP-LICENSE.txt`. https://github.com/twbs/bootstrap/tree/v5.3.3

- Icon HealthConnect là hình học được tạo riêng cho dự án, không dùng logo bệnh viện thật.
