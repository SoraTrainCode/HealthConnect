# HealthConnect — PHP + MySQL

Website thông tin y tế và theo dõi sức khỏe cá nhân, chuyển từ giao diện tĩnh sang PHP/MySQL.

Đọc **[Hướng dẫn cài đặt](website-yte-suckhoe/HUONG_DAN.md)** trước khi chạy. Dùng XAMPP hoặc PHP 8.1+ cùng MySQL/MariaDB; không dùng Live Server.

Chức năng: tin tức, tài khoản, BMI theo tài khoản, admin, chatbot Ollama qua PHP và lịch sử hội thoại. Khôi phục mật khẩu cần cấu hình gửi mail; chatbot cần Ollama/model trên máy chủ.

Bản này không có PDF báo cáo. Nội dung sức khỏe chỉ mang tính tham khảo.
